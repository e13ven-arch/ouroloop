# 回放测试：TDE 的 11 个真实决策点

这个测试回答一个问题：把人换成 Jev，研究循环还能不能转。每一条是 TDE 实验（2026-09-21～22）中的一个真实决策点，包含当时的情况（state）、问题、候选和参考答案。

- `ref_kind: human`（8 条）：参考答案是人当时的选择。
- `ref_kind: outcome`（3 条）：参考答案是后来的结果证实过的决定。
- 目标、权限、对外说法这类应该留给人的判断，没有放进来。

格式与 TDE `Decider` 一致：`type` 为 `noul` 或 `choice`，`criteria` 是各候选的说明；noul 的参考答案是 `yes` / `no`。

运行：`ouroloop replay evals/replay_tde/decisions.jsonl --backend jev --model jev-1.13.0 --out evals/replay_tde/results_jev-1.13.0.json`，报告与参考答案的一致率，以及 Jev 给参考答案的平均概率。只有 11 条，结果只能说明可行性，不能当统计结论。

## 结果（2026-09-22，jev-1.13.0）

| 参考答案来源 | 条数 | 一致 | 参考答案的平均概率 | 平均 Brier |
|---|---:|---:|---:|---:|
| 人当时的选择 | 8 | 8 | 0.87 | 0.049 |
| 被结果证实的决定 | 3 | 3 | 0.85 | 0.103 |
| 合计 | 11 | 11 | 0.87 | 0.064 |

置信度最低的两条："多跳 54%、HotpotQA 96% 是不是数据缺陷"（0.61）和"本期训不训解码器"（0.68）。明细见 `results_jev-1.13.0.json`。

这个结果要打折扣：state 是事后整理的，写进了当时做决定的理由，比决策发生时掌握的信息更有提示性，所以 11/11 只是上限。公平的测试要用决策当时记录的 state，账本和 Claude Code hooks 适配器从现在起记录的就是这种数据。
