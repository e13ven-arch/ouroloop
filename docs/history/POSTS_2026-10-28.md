## Show HN

**Title:** Show HN: reharness – a self-improving agent rewrites its own harness, not its model

**Text:**

reharness is an open-source loop for business agents whose requests repeat. When a request comes back returned, a Revision Session (an LLM coding session) reads the agent's own run — no score, no expected value — and changes the agent's harness: its tools, hooks, skills, prompts. The change is proved with a Live Probe: the candidate runs the same request for real. Only a probe that comes back accepted is adopted, and only for that task. No person picks the change, no model judges it.

What the session is told is typed and bounded: at most "accepted or returned" per attempt, and which check failed. Everything else is frozen — the scorer, the package contract (a candidate may carry no value that belongs to one task), the bounds — and package code runs in an isolated worker.

Numbers (Claude Opus 5.5, AutomationBench): at effort medium the model scores 29.53% on the leaderboard; the same model at the same effort, with reharness, scores 68% at steady state on the benchmark's held-out finance tasks — above the board's best entry at any effort (51.29%). Across sealed finals the loop's harness gained up to +13 points over the same model without it, and no passing task was lost. What it learned, with none of the words in its prompt: open every unread source before writing; derive figures by code.

Code, design docs, journal and every run's cost: https://github.com/e13ven-arch/reharness

## 知乎 / V2EX / 即刻

**标题：** reharness：一个自我改进的 agent，改写的是自己的 harness 而不是模型，每个改动都真跑一次来证明（开源）

**正文：**

业务 agent 的请求是反复到来的。reharness 做的事：一个请求被退回后，一个修订会话（LLM 编码会话）读 agent 自己那次运行——没有分数、没有期望值——改 agent 的 harness：工具、hook、技能、提示词；再用一次实跑探针证明：候选在同一个请求上真跑一次。只有被接受的探针才采用，而且只对这道题采用。没有人挑改动，没有模型当裁判。

会话能被告知的东西是类型化、有界的：每次尝试至多一个"被接受 / 被退回"，加上哪条检查没过。其余全部冻结——评分器、包契约（候选不得带只属于一道题的值）、各项上界——包代码跑在隔离的 worker 里。

数字（Claude Opus 5.5，AutomationBench）：模型在 effort medium 下榜单上 29.53%；同一模型、同一 effort，用 reharness 后在基准的留出 finance 题上稳态 68%，高过榜单任何 effort 下的最高分（51.29%）。几次封存 final 里回路建出的 harness 比同一模型不用它最高多 13 分，没有一道通过题变坏。它自己学会的、提示词里没有的：写入前打开每个没读的源；数字由代码算。

代码、设计文档、开发日志、每次运行的费用：https://github.com/e13ven-arch/reharness
